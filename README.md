# ✈️ flight-light

A WebGL-powered flight tracker that visualises your flight path on a real-time day/night globe and plots the sun's elevation throughout the journey.

## Features

- **Interactive globe** — WebGL2 rendered equirectangular map with real-time day/night blending driven by accurate solar position calculations.
- **Geodesic flight path** — the great-circle route between origin and destination is drawn as a cyan arc on the globe.
- **Sun elevation chart** — an SVG chart shows the sun's zenith angle at the aircraft's position for every minute of the flight, colour-coded by sky phase (day / twilight / night).
- **Real-time & scrub modes** — watch the globe update live as your flight progresses, or drag a slider to explore any point in the journey.
- **Airport autocomplete** — search by IATA code, city name, or airport name from a database of ~9 300 airports worldwide.
- **Timezone-aware times** — departure and arrival times are resolved to the correct local timezone for each airport and displayed in both zones simultaneously.
- **Persistent state** — all inputs are saved to `localStorage` so the page remembers your last flight on reload.

## Usage

1. **From** — type an IATA code (e.g. `SYD`) or start typing a city name and pick from the dropdown.
2. **Departure** — select the local departure date and time.
3. **To** — enter the destination airport the same way.
4. **Arrival** — select the local arrival date and time.

Once both airports and times are filled in, the globe centres on the departure airport and draws the great-circle route. The sun elevation chart appears below the inputs.

Switch between **Real time** (the globe tracks the current moment) and **Scrub** (drag the slider to any point in the flight) using the mode toggle.

## Project structure

```
src/
  App.tsx        — root component; flight form, mode toggle, state management
  SunPlot.tsx    — SVG sun-elevation chart component
  airports.ts    — airport database loader & search helpers
  map.ts         — WebGL2 Map class (shaders, textures, draw calls)
  sun.ts         — solar position calculation (low-precision almanac)
  util.ts        — vector math, geodesic interpolation, line geometry
  hooks.ts       — useLocalStorage hook
  types.ts       — shared TypeScript types (Vec2, Vec3, LongLat)

public/
  airports.txt   — Global Airport Database (colon-delimited)
  earth.jpg      — daytime Earth texture
  night.jpg      — nighttime Earth texture (city lights)
  stars.jpg      — star-field background for the sun chart
  map.vert/frag  — GLSL shaders for the globe map
  line.vert/frag — GLSL shaders for the flight path & sun marker
```
